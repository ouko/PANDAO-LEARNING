# Reusable Code
### 1
Radix separates smart contracts into two parts: blueprints (templates) and components (instances).
### 2
Blueprints define logic and state structure, similar to classes in object-oriented programming.
### 3
Multiple components can be created from a single blueprint, each with its own state but sharing the blueprint's logic.
### 4
This promotes modularity: blueprints do one thing well, encouraging code reuse.
### 5
Developers can earn royalties through a built-in system when their blueprints are used.
